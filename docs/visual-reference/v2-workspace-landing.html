System Parameters. FAQs.

How does the local storage architecture work? expand_more
All session data is written exclusively to your device's IndexedDB and LocalStorage using AES-256 encryption. When you close your browser or clear your cache, the data is permanently destroyed. We have zero backend databases capable of receiving or storing this information.
Can I switch devices mid-session? expand_more
By default, no. Because we use strict local storage to guarantee privacy, sessions are device-bound. However, you can generate a secure, temporary, single-use transfer key to manually migrate an active POJU session to another device if necessary.
What happens if I don't use all my Monthly Pass vouchers? expand_more
Vouchers roll over for up to 90 days. The ecosystem is designed to be used when you genuinely need clarity, not to force arbitrary daily usage.
