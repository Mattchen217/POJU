## 一、铁律（违反过的，都写在这）

### ⚠️ 1. 提示词只给宏观原则与【反例】，严禁给【正例示例】
**实证事故 ×3（全是我犯的）：**
| 事故 | 后果 |
|---|---|
| 底座 few-shot 写了「手机散热片」 | **每个用户的底座都这么说** → 经注入**传染进 POJU** |
| 我建议收尾「这不是命定」 | 模型写出「不是你的**命运**判决书」→ 撞禁词、整篇作废 |
| 提示词禁「引擎」还举了例 | 模型推理里**明说知道禁用**，仍写「你不是一台…**引擎**」 |
**精确边界（已验证）：正例会被逐字照抄；反例不会。**

### 2. 提示词禁 ≠ 代码禁
关键边界（分段隔离、放行、显示什么、禁词）**必须代码硬兜死**，模型会绕道。
**推论**：输入端喂了裸词，就别指望提示词让它别用（Glyph 现在正是如此）。

### 3. 控制面决策、数据面执行
进不进下一段由**用户明确点击**（确认门）决定，不靠模型猜意图。

### 4. 凡是代码能确定的，绝不让模型做
- 排版结构 → 代码按行号打补丁，别让模型重吐全文（它必重排版、洗掉换行）；
- `climate_now` / `refs` → 代码从 structured 填，别让模型猜（它会陷入"大运干支未提供"的无解长考 → 空回复）；
- 长度约束 → 用**句数**不用**字符数**（字符数会诱发计数强迫症 → 烧光 token → 截断）。

### 5. 静默兜底 = 失败永远看不见
matrix-narrative 500 被模板静默盖住、补丁失败被静默整篇重生成 —— **任何 fallback 必须响亮告警 + 面板标注。**

### 6. 对照能成功的基线
遇"同模型 A 路径行 B 路径不行"→ **第一步系统性对比 A/B 代码差异**（base_analysis 流式 job 就是那个对照组），别逐个猜参数。

### 7. xhigh 是高消耗模式
慢(~168s)、吃 token(22000+)、易崩 JSON。**配置按真实胃口给足，别想当然"优化"减配**（我因此连错三版：90s超时 / 12000token / max_attempts:1）。

### 8. 概率性失败的正解 = 同参数无感重发
不追求单次 100% 正确（做不到）；**坏了就丢、同参数重发到成功**（不降质、不换候选、不弹报错）。
**空回复 ≠ slug 失效。**

### 9. 用架构消除整类 bug
确认门(消除猜意图) / 异步job(消除90s墙) / 同参重发(消除偶发露底) / 代码物理隔离(消除改A坏B) / 双层制(消除专业与可读打架)。

### 10. 单一事实源
禁词表/黑名单/术语表 **只能有一份**，门禁+替换器+提示词**全部从它读**并**自动注入** —— 三份表分开维护必然漂移（`日主`/`引擎` 就是这么漏的）。

## 二、已验证的系统事实

### 底座（命主基础分析）
- **两层**：Layer1 给机器（`structured` + `core_judgments`）／Layer2 给人（叙事，**绝不注入下游**）；
- **目标 2 次调用**：core_judgments 1 + 叙事 1（欢迎词已改**纯模板、0 调用**）；
- **门禁只拦叙事**；`core_judgments` 无用户可见文本 → 第一次即落库；
- 神煞闭集 **24** 个（`CLOSED_SHEN_SHA` / Block 62）；本盘只用实例清单实算项；`国印/将星/月德/天德/学堂` 等已在闭集内（算出才可写）。

### 四产品交付结构（已定案）
```
正文（纯白话 · 零标记 · 有温度）
  ▸ 结构依据（默认折叠 · 金字集中 · 允许"不好读"）
```
- **结构依据 = 支撑该段结论的【最短承重证据链】**（2 句 / ≤3 金字），**是引证不是推理实录**；
- **依据先行**：先锁 2–3 锚点 → 据此推结论 → 写正文 → 落依据。**自检：删掉依据，结论还站得住？站得住＝泛泛而谈＝重写。**
- **它是逼模型真算的枷锁**，不只是给用户看的证据。

### 三命名空间 + 冲突
| ns | 产品 | 需命名 |
|---|---|---|
| bazi | 底座/POJU/Match | 99 |
| qimen | Syncro（**完整奇门引擎**，`qimen_data` 已藏 `_internal`） | ~39 |
| glyph | Glyph（**100 签观音灵签**，无卦闭集） | 17 |
**冲突**：①「白虎」qimen 合法 / bazi 禁词 → **禁词按空间隔离**；②「六合」同名不同义 → **以 ns+slug 为键**；③ 八門含**死/伤/惊** → 改名刚需。

### 合规
- **三层防御**：门面层零专业词（**欢迎词/标题也是门面**）／内部输出控观感／行为底线（不预测祸福、不占卜宿命、不恐吓、不诱导消灾）；
- **审计正则**（`audit-output.ts:119`）已禁：日主|用神|忌神|大运|流年|十神|七杀|食神|伤官|命盘|奇门|遁甲|算命|命理 → **"在结构依据里加(用神)"会被直接拦**；
- **大运年龄段 = 算命核心特征 → 用户报告零大运**；时机只留 `climate_now`（无年龄/干支/公历年）；
- **合规只查输出，不查 reasoning** → 模型可裸算，输出必软译。

### POJU 第2段（已跑通）
**A/B 拆分**：A(xhigh) 86.6s/reasoning 4,068 出报告 → 锁输入 → B(high) 16.3s 出承上启下提问 → 解锁。
**关键**：拆的红利一半来自任务变小、**另一半来自规则变少（每次只带自己那份规则）**。
