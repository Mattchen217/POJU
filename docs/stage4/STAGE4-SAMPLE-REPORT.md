# Stage 4 Sample Report Artifact (deterministic · no LLM)

Generated by `buildStage4SampleFromFrozenDc()` from a frozen Decision Context.  
This demonstrates binding + P5/P6/P8 structure; it is not a live OpenRouter book.

## Binding

- `context_id`: `dc_stage4` (fixture)
- `context_version`: `1`
- `content_hash`: computed at Freeze (see test run)

## Face 05 — P5 Decision Options (shape)

- **first_choice**: Conditional preferred path aligned to decision question  
- **second_choice**: Phased / reversible alternative  
- **caution_choice**: High-commitment path deferred  
- **switch_or_stop**: Switch if preconditions fail; stop if unacceptable outcomes become likely  
- **recommendation_conditions**: Unknowns / boundaries that may change ranking  
- **evidence_trace**: `fact:…` / `hypothesis:…`

## Face 06 — P6 Verification Experiment (7 questions)

| Field | Role |
|---|---|
| hypothesis | What assumption is being tested |
| action | Bounded reversible trial |
| observe | What signal to watch |
| window | Observation window (no invented KPI) |
| success_criteria | What counts as enough signal |
| if_fail | Adjust / stop / rerun — not silent escalate |
| defer_costs | Costs that must not happen before verification |

## Face 08 — P8 Review

- **shared_core_metrics**: Must overlap P6 observe / success_criteria  
- **review_decision**: `continue` \| `adjust` \| `stop` \| `rerun`  
- **review_decision_rationale**: Trigger + evidence + sufficiency
