## 功能与交互

### 导航锚点滚动

- 点击目录项 → 平滑滚动到对应条款
- URL hash 同步（如 `/disclaimer#section-3`）

### 打印友好

页面应支持浏览器"打印为 PDF"（用户可能想保存一份）：
- 打印时隐藏导航栏 / Footer
- 保留全部内容清晰可读
- 使用 CSS `@media print`

### 返回按钮

顶部左侧小按钮 `← Back`（如果来自弹窗）：
- 检测 `document.referrer` 或 URL query
- 如果来自免责弹窗，点击 → 返回并重新打开弹窗
