# 14 · 404 错误页

## 页面身份

| 项 | 值 |
|---|---|
| 路由 | 捕获所有未定义路径 |
| 文件位置 | `app/not-found.tsx`（Next.js 约定） |
| 页面标题 | `404 — POJU` |
| 目标用户 | 访问不存在路径的用户（笔误 / 过期链接 / 探索） |
| 核心目标 | 用 POJU 风格的诗意方式引导用户回到主路径 |
| 优先级 | 必须（Task 1） |
| 所属 Task | Task 1 |

---

## 访问条件

- 自动触发（Next.js 未找到匹配路由时）
- 所有人可访问

---

## 页面结构清单

1. POJU Logo
2. 主提示文字
3. 三个快捷入口
4. Footer

### 文案细节

**标题行**：`404 · This path doesn't exist.`

**诗意副标题**（POJU 风格）：`Sometimes the way forward is going back.`

**主按钮**：`Return home`
- 样式：Primary 紫色 pill
- 点击：跳转 `/`

**分隔线文字**：`Or start here`

**三个快捷入口**（垂直排列）：

#### Start with POJU $9.99 →
- 点击：触发 Stripe Checkout
- Stripe metadata: `source: "404_page"`

#### Open Syncro →
- 点击：跳转 `/syncro`

#### Open Oracle →
- 点击：跳转 `/oracle`

### 视觉氛围

- 背景：深色 + 极少量紫色粒子缓慢飘过（营造"迷路在宇宙"感）
- Logo 稍微呼吸（opacity 0.8 ↔ 1.0，3 秒循环）
- 动画保持克制（不要过度）

---

## 功能与交互

### 所有按钮

- 标准 hover 效果（-2px 上浮 + 光晕）
- 点击动画（200ms）

### 键盘支持

- Tab 键依次聚焦四个按钮
- Enter 键激活当前聚焦按钮

### 自动重定向（可选）

**不默认做**，但如果日志显示某些 404 路径高频，可以配置特定路径重定向（例如用户笔误 `/pjo` → 自动跳 `/poju`）。

## 数据依赖

### 需要的数据

### 需要调用的 API

- 无（所有 CTA 点击时才调用）

- **不记录用户 IP 或其他识别信息**
