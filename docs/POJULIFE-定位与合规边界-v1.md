# POJULIFE 项目定位与合规边界文档 v1.0

> 本文档是 POJULIFE 全站文案、Prompt、输出防线的**唯一基准**。
> 核心原则:**保留东方文化的灵魂,守住支付网关的红线。**
> 一句话:可以大谈五行哲学,但绝不用五行去算命。

---

## 一、项目本质

POJULIFE 是一款 **基于《易经》框架的东方智慧决策支持工具**。

它将东方哲学(易经变化之道、阴阳五行能量模型、东方整体观)与现代决策科学、心理学结合,帮助北美用户(含华人移民)在人生决策、时机选择、关系兼容、自我认知等方面获得洞察与支持。

**卖点**:东方智慧的独特美感 + 实用的决策与心理支持。

**定性**:不是算命工具,是"东方哲学 + 决策科学 + 心理学"的现代化产品——如同西方包装占星(Astrology)、塔罗(Tarot)那样,把东方能量系统包装成一种 **古老的东方能量分类学(Ancient Eastern Energy Classification)**。

---

## 二、哲学根基(项目的灵魂,必须体现)

这些是 POJULIFE 区别于普通 SaaS 的灵魂,**必须在输出中自然体现**:

1. **《易经》变化哲学**:时位(timing & position)、阴阳、变化之道、否极泰来。这是全项目的哲学框架。
2. **五行能量模型(Five Elements / 五行)**:作为"东方生态能量分类学",描述性格与能量平衡,类比西方四元素(地水火风)与星座元素。
3. **阴阳平衡(Yin-Yang)**:对立统一、动态平衡。
4. **东方整体观(Holism)**:人与时间、空间、环境的能量共振。

**五大功能定位**:

| 功能 | 对外定位 | 哲学锚点 |
|---|---|---|
| POJU | AI 认知伙伴(东方哲学对话) | 易经变化之道 |
| Glyph | 原型隐喻反思(Archetypal Reflection) | 易经情境哲学 + 荣格原型 |
| Syncro | 时空效率矩阵(Spatiotemporal Matrix) | 易经时位 + 五行能量共振 |
| Match | 兼容性评估(Compatibility) | 阴阳互补 + 五行生克平衡 |
| base_analysis | 性格能量画像 | 五行 + 易经 + 性格科学 |

## 三、合规底线(绝对红线,任何阶段都守)

这五条是**铁律**,任何东方文化内容都不得触碰:

- 🔴 **不算命**(no fortune-telling):不以公式断人一生命运。
- 🔴 **不预测具体未来事件**(no prediction):不说"X 月会发生 Y""你会在某时结婚/发财"。
- 🔴 **不占卜**(no divination):不起卦、不抽签算命、无求签解签流程。
- 🔴 **不决断吉凶**(no verdict):不说"大吉/大凶/必成/必败/破财/运势大凶"。
- 🔴 **不恐吓收割**(no fear-mongering):不制造恐慌,不"付费消灾解厄"。

> 守住这五条,就避开了出海 90% 的灭顶之灾(高拒付、欺诈嫌疑、封号)。

## 四、允许 vs 处理 vs 红线(精准三层边界)

### ✅ 第一层:允许(东方文化的灵魂,大方保留)

作为**能量模型 / 性格描述 / 哲学框架 / 心理调节**使用时,这些可以保留:

- **五行**:Fire / Metal / Earth / Wood / Water + 金木水火土
  - 作能量分类、性格特质、平衡建议(像四元素、像星座元素)
- **阴阳**:Yin-Yang
- **《易经》/ I Ching / Book of Changes**:作哲学框架(变化、时位)
- **气(Qi)、道(Tao)**:作哲学概念
- **五流等级**:通流/顺流/守静/逆流/暗潮(Open/Following/Stillwater/Crosscurrent/Undertow)

**范式(参考 Gemini 的优秀例子)**:
> "In Eastern philosophy, your core nature resonates with the **Wood element**(木)— growth, flexibility, intuition. You're navigating a cycle of high **Fire energy**(火), which can over-stimulate Wood's gentle growth — explaining current impatience. To rebalance, introduce the grounding **Earth element**(土) or the reflective **Water element**(水)."
>
> → 保留木火土水,作能量模型 + 心理调节,**不预测、不恐吓、不断吉凶**。

### 🟡 第二层:处理(概念保留,术语软化)

八字的**洞察**可以用,但**专业排盘术语**要翻译成能量/性格语言(英文直译太"算命"):

| 命理术语 | 软化为(概念保留) |
|---|---|
| 日主 / Day Master | 核心特质 / core nature |
| 用神 / Yong Shen | 关键平衡能量 / balancing element |
| 忌神 / Ji Shen | 需留意的能量 / quality to watch |
| 十神(七杀/食神/伤官等) | 关系动力 / 行为动力 |
| 大运 / Da Yun | 人生阶段 / life cycle |
| 命盘 / 命局 / chart | 性格画像 / profile(避免排盘工具感) |
| 干支排盘(乙木/丙午并列断语) | 阶段能量描述 |
| 奇门 / Qimen / 风水 / Feng Shui | 时空能量分析 |

### 🔴 第三层:红线(不出现)

- 预测具体未来事件(will + 日期/事件)
- 吉凶决断(大吉/大凶/必/破财)
- 恐吓收割(付费消灾)
- 起卦 / 抽签 / 占卜流程
- "in your chart"(命盘排盘标志)→ 用 "in your profile"

## 五、措辞风格指南

把东方系统当成"高级文化符号和能量标签",像西方包装占星/塔罗:

1. **描述"你是谁"(性格)+ "当下能量"(环境)+ "如何调节"(心理/行动建议)**
2. **不预测"会发生什么"(结果)**
3. 用"能量 / 共振 / 平衡 / 调节 / 倾向",不用"克 / 泄 / 预测 / 吉凶 / 注定"
4. 五行作能量分类学(像四元素),不作生克算命
5. 《易经》作哲学透镜(变化之道、时位),不作占卜(起卦)
6. 产品名指代:POJU(第一人称)/ 这个 Glyph / 这个 Syncro / 这个 Match
