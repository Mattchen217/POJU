## 记下的点

1. **神煞落点未先核事实档**  
   第 1 张写「月柱词馆入命」。若本盘事实档没有「词馆」，属于盘外神煞；当时闸门没拦下（可能不在神煞名扫描表，或未进档）。  
   后续：专写/闸门凡写神煞名，必须能在事实档 `shen_sha` 里对上；对不上就不合格。换人换题同一条。

2. **十神标签盖住整步大运**  
   第 1 张写「大运壬寅正官当令」。对本盘己土：寅木才是正官，壬水是正财。只标正官会偏掉财星用神一面。  
   后续：大运两干支若十神不同，批断须分开写（或写全），禁止用一个十神称呼整步运。

3. **贵人 / 正官 → 律师的跳跃**  
   第 1 张：月德/太极贵人、正官 →「易得律师或法务资源」。命理引申可以有，但收束句几乎等于访谈结论，承重偏薄。  
   后续：职业/角色落地须多一句盘上因果（哪柱、哪运、哪用神），禁止贵人二字直接跳到具体职业。

4. **「资源方」第三人称能力断言**  
   第 0 张：「印旺则资源方自身具备学习与整合技术之能」。本盘只能论问象侧结构，不应用问象的印去断言对方会不会技术。  
   后续：解释层主语保持「你」/本盘结构；对方只作议题对象，不作能力主体。

5. **比劫「多现」略满**  
   第 0 张用丑未冲 + 比劫释「缺执行者」。地支土多、日主己可论比劫气，说「局中比劫多现」略满。  
   后续：执行者象须扣住本盘实有的比劫/食伤受制等，避免「多现」一类夸大。
