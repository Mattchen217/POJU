## 五种必要性（现实信息）

| 值 | 含义 |
|----|------|
| `required` | 作出具体判断需要证据；可 worth 追问；未知/拒绝后保留边界，不得无限追问 |
| `conditional` | 仅当适用条件成立时需要 |
| `optional` | 加深解释，不阻塞交付 |
| `defaultable` | 中性表述或由上游/代码推导；不问用户、不编造事实 |
| `none` | 本段不需要新的用户现实信息 |

`required` ≠ 用户必须回答。`ask_policy` 与 `decision_materiality` 共同决定是否在 material 时追问及是否影响 readiness。
