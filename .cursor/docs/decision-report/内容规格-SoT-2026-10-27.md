## 双轨三层

1. **推理层**：生成前：凡出主主张的页，提示词先做命理结构推理 + 科学机制推理，再写正文
2. **依据层**：用户可见固定段：A 命理（真算锚）· B 科学（本案机制，禁空术语）· C 汇合（短）——删段三问验收
3. **正文层**：01/05/06 写「怎么走」，不强制每句挂双轨；承重时指回 02 或本页 A/B

同页分段 A/B/C，不每句双嵌，不砍科学。

## 01 本题断语

- 用户带走：这件事眼下更该怎么走
- 语气：硬、明确；禁止模棱收束
- 双轨：不展开论证；一句「依据见 02」
- 段：A 主推荐（1～2句，方向动词）· B 成立条件（2～4 bullet）· C 不选什么（1～2句）· D 依据指针（1句）
- 禁止：本页展开全盘、逐宫朗读、恐吓后果

## 02 为何如此

- 用户带走：为什么信这个断语
- 双轨：主承重页 A+B+C 必出；D 可核对锚短表
- 段：A 命理理由 · B 科学机制 · C 汇合 · D 可核对锚（≤6行；紫微未稳可只出八字）
- 禁止：十二宫全列、神煞大全、与题无关六亲展开

## 03 盘面附录

- 不进主翻页；包尾固定；入口标「附录」
- 段：A 八字本题切片 · B 紫微本题切片（未稳则整段跳过，不注水）· C 对照一句
- 可与主叙事并行生成；不挡主 6～7 面出包
- 命理为主；不要求科学双段

## 04 真正卡点

- 段：A 卡点命名 · B 表现 · C 若硬顶会怎样（禁灾祸恐吓）· D 依据（可折叠 A/B）

## 05 路径排序

- 段：A 首选 · B 次选 · C 慎选 · D 何时切轨/停止（**必出**）· E 对照一句
- 路径须 2～4 条；不可只写空泛「平衡发展」

## 06 怎么落地

- **禁勾选作业**：不要「3～5 条可勾选」。要动作类型 + 完成样貌
- 段：A 近步原则 · B 阶段气候 · C 执行中的自我调频 · D 节奏提醒
- 禁止：择日开运、流日主星播报、符咒消灾、假日历提醒

## 07 场域与关系

- 仅当问题属事业换场、迁移、合伙、亲密关系、joint 双人题时插入；否则整页跳过
- 段：A 场域判断 · B 关系/互动 · C 依据（可折叠）· D 与 01/05 对齐
- 禁止：合婚分数、克应恐吓、对方人品定罪

## 08 自检清单

- 段：A 红灯信号（3～5）· B 复盘问句（3～5）· C 何时重跑本题

## 恐吓红线（唯一硬红线）

允许带条件的明确主推：本题更宜 A，条件是…；B 仅在…时考虑。可以说硬扛成本高、更宜降档。允许传统术语配决策白话。允许大运 / 大限级阶段利弊。

禁止恐吓与逼迫，包括：必散、必死、某年大祸、不听就败。也禁止灾祸恐吓、克应恐吓、合婚恐吓、付费消灾。词表在 `lib/llm/compliance/audit-output.ts`（`SCARE_REDLINE_PHRASES_*` / `textHitsScareRedline`）。扫描接入交付闸门留给后续提示词波次；W0 只对齐词表。

明确主推词干（更宜 / 条件是 / 仅在）不是恐吓，不得写进禁表。
