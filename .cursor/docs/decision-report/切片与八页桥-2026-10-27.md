## 切片省略

缺包、null、空串、空数组、空对象：该键不出现。一组里没有任何键，连组名也不写。不再留 W0 那种全 null 空槽。

| 情况 | 切片 |
|------|------|
| 没有 `ziwei` / `zfp`，或允许键上都没值 | `zfpOmitted`，没有 `zfp` |
| `zfp: {}` | 同上。空对象不是一份盘 |
| `otherChart: null` | 省略该键 |
| 页 sci 为否，或没给 hooks | 不写 `sci`，也不写 `sci: null` |
| User 某键是空串，或不在该页并集 | 省略该键 |

八字包只投影三样：`day_master` → dayMaster；「用神 / 喜神 / 忌神」三行 → yongJi；「当前大运」一行 → dayunNow。柱行、流年、流月、合冲刑害、`text` / `ganzhi` / `shen_sha` 不进任何页。

pathTags、shishenHit、conflictAnchors 只接受调用方放进 `cfp` 的短键。不从全文猜。短键盖过投影；短键给空则去掉该键。

topicPalace 默认是包内命宫，去掉 `role`。`career_move`→官禄，`relocation` / `迁移`→迁移，`partnership` / `合伙`→仆役，`relationship` / `joint` / `亲密`→夫妻。也可以直接写十二宫名。对宫用 `palaces` 的下标加 6，切片只留这一宫。`palaces` 和 `source` 不进页。找不到目标宫时退回命宫对象。

`segments` 仍是矩阵上的段级代号。填好的值只在 `slice`。直接调用 `sliceForPage("07")` 会返回 07 的切片；阅读序是否插入 07 看 `readingOrderForTopic`。
