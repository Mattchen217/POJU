## 产品本质

交付报告本质上是一份**钉在这个人主盘上的专业命理批断**（依据层）+ **用户真正要用的正文**。

正文和「易读依据」都是后加工，不是源头：

1. 先基于本地计算结果写出命理批断（专业词 + 命理逻辑）。
2. 再写用户可见正文：
   - **P2**：把这份批断译成通俗归因正文。
   - **P3+**：写出可执行策略/行动/调频/熔断/出门；批断证明「只对本盘成立」，**题材不是机制链复述**。
3. （第二步）再把**同一份**批断做成依据层：自造术语替换 + 大白话连接，便于阅读和多语言。

不是先写正文，再补一段依据。依据若不是批断的出处，就只是多一段正文，没有存在意义。

```text
本主盘本地算
    → 命理批断（专业全文，依据源头）
        → 正文（P2=白话翻译；P3+=可执行内容，批断扎根）
        → 依据呈现（第二步才做：同一批断的软标 + 白话连接）
```

不适用命理批断的段落：**不要写依据**，只给正文。

自检（P3+）：把正文里「合力」「调节力」「输出表达」「过载」这类结构隐喻整句删掉，剩下若是空的或只剩「因此需要平衡」→ 不合格。
## 本地计算的唯一目的

让模型的推算落实到**这个人的主盘**，不飘到无关的盘。

- 围绕本主盘的推算都合格。不能用「少乱造 slug」去限制模型的推算能力或命理词条数。
- 唯一要拦的是：飘到他盘、引用本盘没有的实例、永禁恐吓词。
- 一卡只锁 1 个词是错误药。它能减少乱改 slug，但依据不再是批断，整段依据失去意义。

## 现状（为何依据只有 1 个金字）

本地 `ProfileStructured` 有全盘实算。喂到依据承重的却是漏斗：

## 正确的 Range

Range = **本主盘** structured 实算、可引用的词。过滤只服务「防飘盘 / 防假实例」，不服务「少写几个词」。

| 要 | 不要 |
|----|------|
| 本盘实算词尽量可见，模型在范围内自由写批断 | 每卡固定 1 槽或固定 K 冒充密度 |
| 闸门验「是否落在本盘」 | 闸门验「每段 ≤N 个金字」 |
| 缺自造术语 → 第二步补 `POJU_TERMS` | 因表缺词砍批断 |

仍排除：永禁恐吓词（`OUT_OF_SET_FORBIDDEN_HAN`）、本盘没有的神煞实例、空壳占位。不解禁这些来换密度。

## 第一步画面（依据槽）

有承重的卡片固定三层，顺序不能反：

1. **正文（各页用户可见段落）**：白话，零命理词。
   - **P2**：必须是下面这份批断的翻译（表象 / 本质）。
   - **P3/P4/P5/P6**：可执行内容（科学策略 / **东方谋略三柱** / 熔断 / 出门）；批断在折叠依据里证明「只对本盘成立」。禁止把批断机制链译成正文题材。P4 规格：`P4-东方谋略-规格锁.md`。
2. **折叠「底层依据」**：原样命理批断（真词句读，不是一两个金字，也不是另写的大白话）。

示例批断可以和示例正文无关，只说明版式。真报告里批断必须先写，并且就是依据出处。不适用批断的段落不出现这一折。

当前实现：专写按本盘真算写批断；打标先原样通过、不做软标；依据折叠把 `⟦w:真词⟧` 还原成一段可读批断。软标替换仍是第二步。

## 分步执行

### 第一步（当前）：正文 + 依据里的原样命理批断

依据折叠里就是专业批断本身。先看质量像不像批断。

做：

- 去掉每卡固定 1 锁。给本盘 Range，模型自由写多词批断，条数不设上限。
- 只拦盘外、无实例、永禁词。
- **P2** 正文 fill 只翻译已有批断；**P3+** fill 长出可执行正文（菜单/主辅/处境承重），批断只扎根，不得另起与盘无关的鸡汤。
- 依据槽原样挂批断，让人能读到专业词。
- 不适用批断的槽不挂依据。

第一步不做：

- 不做自造术语替换。
- 不把批断改写成现在那种一两个金字的白话依据。
- 不补 `POJU_TERMS`。
- 若 `auditDeliveredText` 会剥掉依据层真词，本步只对依据槽放行原样批断；正文仍白话。不要提前做替换。

第一步验收：

- 依据是多词、有机制的命理批断（密度接近「得令得地、干透、半合、身强、金水相涵」这类），且每个词可溯本盘。
- 正文是这段批断的白话译。删掉依据后，命理出处不成立。
- 无批断的段落没有依据折叠。
- 盘外词失败。回归去掉 `exactly one signal per card`。

合格批断形态（真词版，第二步才换成自造术语）：

> 日主丁火，生于午月，建禄当权，火势炎上。干透丙火帮身，地支寅午半合火局，局中木火偏旺，日主得令得地，身强之象。月干透出癸水七杀，然无庚辛发源，地支无根，显虚浮。局中燥气太重，急需金水相涵以成润局。

### 第二步（第一步质量达标之后）

同一份已验收批断：

1. 命理真词 → 自造术语（`lib/glossary/pojulife-terms.ts`，依据层 `⟦w:⟧` / `⟦t:⟧`）。
2. 用大白话把这些术语连成易读段落（可难于正文，但可读、可译）。
3. 批断里出现、表中没有的合法真词 → **补表**，不回头限条数。
4. 正文保持第一步的白话译，不把金字灌回正文。

第二步验收：依据仍是同一批断，只是真词换成软标并用白话缝起来；缺词有补表记录。

易读依据形态（第二步目标，【】处为自造术语）：

> 你的【天干】上还有【丙火】透出来帮忙【帮身】，【地支】里的【寅木】和【午火】又半合成了火局。整个格局里的【木火】偏旺，既占了时令【得令】，又占了环境【得地】，是标准的【身强】。盘里燥气太重，最急需的是【金水相涵】，靠金与水互相滋养来降温润局。

## P2 归因（2026-09-21 定稿 · 已按此实现）

P2（`foundation`）是归因分析，不是把收集回答填进卡片再补一段解释。

2026-09-21 Lab attempt #2 正文不合格：五张 `surface` 都是问答原句。原因是代码把收集答案做成「P2 表象候选菜单」，并写明 `why_card.surface` 必须回溯该菜单（`foundation-surface-feed.ts`、finalize 脊柱「论证铁律」）。模型的任务被收成：填入回答，再编本质和批断。

### 数据从哪来 · 要不要挪到后面

归因**不需要**其他页的正文。开工时本地就算完的材料够用：

| 要喂 | 不要喂 |
|------|--------|
| 本盘事实档（日主、四柱、藏干、用喜忌、合冲、大运流年、本盘神煞、**奇门锁盘摘要**） | P1 直答、P3 手段、P4 东方谋略、P5 熔断、P6 收束的已生成正文 |
| 用户的问题与期望 | 「表象候选菜单」当作唯一合法 surface |
| 已收集处境（发生了什么、约束是什么），只作材料 | 把某一条回答原句锁成某张卡的表象 |

这些在六页正文之前就有（`ProfileStructured` + 问题 + `covered_agenda`）。正式 DAG 里 P2 与 P3、P4 同属 Wave A，只等自己的 finalize 脊柱，不等兄弟页。这个顺序是对的：**P2 继续放在前面生成。**

后面的页才该等 P2，而不是反过来。P3 手段、P4 东方谋略应从这份归因长出来。那是下游改依赖，不构成把归因挪后的理由。P5/P6 仍等 P1+P3+P4（现有 `wave_b.gate`），与本次无关。

### 正确产物

一次归因挖出 4–5 条。每条顺序不能反：

1. **命理批断**（无标记原文，钉在这张盘上）——唯一出处。
2. **表象**：这条批断在眼前处境里可见的现象，白话，零命理词。不是访谈原句。
3. **本质**：同一条批断的机制白话，零命理词。

删掉批断后，表象和本质都不能独自成立。禁止先写本质再回头编批断。禁止把访谈原句整段贴进表象。

人设、任务、目标只写在 P2 这一步的任务块里，不进全阶段身份层。

### 调用形态

任务重就拆，不把多枪塞进同一次 300 秒。

1. **发现**（一次全新 invoke，xhigh，270 秒）：代码先列出这张盘的全部合法关系（合冲刑害，以及十神生克全表上方向正确的透干、日主、地支本气、运岁天干）。模型只读问题、处境材料和这张清单，回 4–5 个互异编号。代码按编号绑上结构句和事实档摘录。模型不写新的生克，不写摘录。编号不在清单里就失败，不把原句削短当成通过。
2. **专写**（一卡一次 invoke）：无因果的卡间隔约 1 秒同时发出。每卡只写该主张的无标记批断。
3. **合并**：原样齐套，不砍薄、不并成一段。
4. **正文**：表象和本质都只翻译该条批断。
