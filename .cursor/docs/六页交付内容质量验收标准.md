# 六页交付内容质量验收标准（参考尺）

**用途**：Lab 点跑或读拼书预览时，用可勾选条目判断**用户会读到的内容**是否够格——不是「读起来顺不顺」的模糊感觉。  
**角色**：内容质量参考尺（合格 / 加分 / 减分）。与步骤过程尺、活文档分工如下：

| 文档 | 管什么 |
|------|--------|
| [`Delivery-Lab-30步分步验收标准.md`](./Delivery-Lab-30步分步验收标准.md) | **每一步**中间产物能不能放行 |
| **本文** | **六页内容**值不值钱、有没有护城河 |
| [`pivot-八页交付验收标准.md`](./pivot-八页交付验收标准.md) | Canonical 产品尺（用户该带走什么）；本文是其 Lab 友好展开，**不替代**它 |
| [`delivery-lab-分步验收标准.md`](./delivery-lab-分步验收标准.md) | 活文档：F/P 签字、踩坑、回归（**用途不变**） |

**用语对齐**：合格线 ≈ 活文档 **F**（不过则打回）；减分项 ≈ **P**（可放行须登记）；加分项 = 正向样本。  
**禁止**：合格线失败后靠 LLM「再试一次说不定过」（规则 11）——优先改种子/菜单/软修/显式 fail。

## 零、通用红线（所有页先过这一层）

| 检查项 | 说明 |
|--------|------|
| **删依据自检（护城河 · 最高）** | 去掉命理依据后，策略/节奏/避坑是否仍「谁都适用」？仍成立 → **不合格**（未从盘长出） |
| **议题不污染事实** | 同盘同 `as_of`、不同议题：真算判断内容一致，仅详略可变。适用于总纲与 assign 选词 |
| **无编造** | 真算缺失时写「未见相关特征」类否定，禁止为完整感凑数 |
| **removal_test 真实** | 不能无脑 `passed: true`；同单元多信号 role/inference 高度可替代 = 冗余 |
| **无第三方施事** | 本盘信号不断言另一具体人物的心理/行为；已知第三方仅话题/背景，不作动作主语 |
| **无半渲染残骸** | 禁裸 `【】`、未闭合 `⟦w:` / `⟦t:`、连接模板词同段重复 |
| **五行关系链复杂度** | 单句 ≤2 元素 +1 生克；超则拆句；禁止变量括号拼接 |
| **locale 分层** | assign/write **允许**命理本字；**mark 之后**用户可见依据层：禁用词→品牌词；英文 token = 0；五行单字点缀可保留 |
| **不替用户执行** | 禁「我们会帮你联系/处理」；只给用户自己的行动建议 |
| **主辅一致** | P1 主路径与 P3/P4 展开、题向收敛一致，禁止前后换轨 |

## 一、上游：Thesis 与 Prealloc

### Thesis · 命盘总纲

**合格线**
- 六维齐全；`day_master_strength` 最先；强弱维显式引用 `strength_verdict`
- present/absent 如实；藏干「透干 / 藏而不显 / 皆无」分开，禁把未透干当无
- 同盘换议题：`classical_basis` 与判断性 `conclusion_zh` 一致，仅 depth 可变
- 同盘换 `as_of`：`cycle_rhythm` 正确步进；缓存 key 区分日期
- 未扩维神煞/长生不进承重 present

**加分项**
- `conclusion_zh` 连贯批断，非 checklist 拼接
- 强弱前提写进下游结论文字

**减分项**
- stub 未标「引擎未实现」
- 两维定义同一概念措辞冲突 → 术语 SSOT

### Prealloc · 全书 primary

**合格线**
- 池 = 总纲 closed menu；每项可在 Thesis present 精确核实（含关系 kind）
- 无影子池（神煞/长生/历史大运/元男占位）
- 全局复用 cap；不够则 sparse 减槽，禁止 inventory 回灌

**加分项**
- 六维引用相对均衡

**减分项**
- 触顶无补位（非 sparse 预期时）

## 二、逐页验收

### P1 · 直答（`direct_answer` · 仅 fill）

**核心职责**：正面回答所问；主路径一句话说清。

**合格线**
- 明确主路径，非「两条路各有利弊」
- 与题向收敛及 P2–P6 实际展开一致

**加分项**
- 开篇一句即有方向感

**减分项**
- 大量「或许 / 视情况」模糊主张

---

### P2 · 根基/表象（`foundation`）

**核心职责**：为什么是他；用户自述表象如何对到命盘结构。

**合格线**
- 每条 `slug`+`dimension_id` 可在 Thesis 核实（closed-menu）
- **无第三方施事**（本页历史高发）
- 每卡推论针对本表象**新导**，非同信号换汤不换药
- 删掉依据后「为什么卡」应不成立

**加分项**
- 藏干兼藏根气织进推论

**减分项**
- 防第三方句模导致多卡雷同（已知权衡，可放行须登记）
- `why_needed` / `unit_claim` 明显单薄或粘贴 cite
- 表象候选 label/answer 错配（若导致事实错 → 升合格线失败）

---

### P3 · 科学行动（`science_action`）

**核心职责**：可执行的行为/精力策略；护城河之一。骨架从总纲 + 题向收敛长出。

**合格线**
- 建议具体可执行（时间/频率/动作），非万能鸡汤
- 药方可追溯命盘 + 题向；**删依据后不成立**
- 主轨 / 辅轨 angles **各 3**（或本盘锁定数）；口径写入策略/手段，无独立长剧本槽
- 禁替用户执行

**加分项**
- 数字/约束对齐收集段现实（如每周仅 5–8 小时）

**减分项**
- 删依据后建议仍成立（泛建议）
- 辅轨多角 **unit_claim / 药方同模**（只换命理外套）——记 P，根治在 assign 种子，勿空转重试 write
- 单卡 evidence 软修过短、撑不起 claim（如比肩关系卡）

---

### P4 · 东方行动（`metaphysics_action`）

**核心职责**：时机 / 极性 / 格局等东方维；护城河；**历史上问题最集中的一页**。

**合格线**
- 关系链严格 ≤2 元素 +1 关系/句；无裸括号、无模板连接词堆砌
- 时机裁决只来自总纲 `cycle_rhythm`，禁止他环越权定「该冲该守」
- **删依据不成立**；色/向不得单独定义整页补泻
- **禁复读 P3** 科学职场手段；锚定问题+期望，非主辅轨复读

**加分项**
- 时机挂钩当前大运/流年具体干支，能看出「为何是现在」

**减分项**
- 调候整段生克推演即使未撞禁用词 → 标记合规复核
- narrative 降级顶替真算维

---

### P5 · 风险熔断（`risk_guard`）

**核心职责**：盯住 P3/P4 行动的红灯、自检、切辅。

**合格线**
- 红灯可自检（用户能判断「我是否踩了」）
- 禁脏腑、疾病名等医疗表述
- 处置链删依据后应垮；禁另立无关 KPI 议程

**加分项**
- 明确挂钩总纲事实（如官杀重+身弱 → 避免多头承诺）

**减分项**
- 红灯过宽，不知在何场景警觉

---

### P6 · 收束信号（`signals_close`）

**核心职责**：近阶可观察信号 + 收尾；不替做执行。

**合格线**
- **可观察信号**，非「某月某日会发生 X」事件预言（本页最易滑向宿命论）
- 「信号出现时可考虑…」，非「到时候我们会…」

**加分项**
- 信号具体可自我核验（如「连续两周不再纠结时」）

**减分项**
- 「未来三个月有转机」类时间预测，即使包装成提示也应改写成行为/心态信号

---

### Assemble · 预览拼书

**核心职责**：页间一致性，不是重做单页。

**合格线**
- P1 ↔ P2–P6 无互斥
- 无流展式跨页重复诊断
- locale / 残骸扫描 = 0

**加分项**
- 六页多角度支撑同一套判断

**减分项**
- 多页重复用力、论点覆盖不均

## 三、四点用户价值对照（来自 Canonical）

评完整拼书或关键决策页时，再扫一遍：

| # | 用户该带走 | 本尺落点 |
|---|------------|----------|
| ① | 清晰答案 | P1 + 主辅一致 |
| ② | 只属于他的理由 | P2 + 删依据 |
| ③ | 可动手策略（科学+东方） | P3 + P4 + 删依据 |
| ④ | 自检与回来的路 | P5 + P6 |

四条都成立 → 内容达标；缺 ① 或 ③ 且无命理扎根 → 整份失败。

## 四、如何使用

1. **步骤**：先过 30 步尺合格线 → Gate PASS → 再过本文对应页 + 通用红线。  
2. **减分项**：不挡 unlock，**当日写入活文档**；跨页反复出现 → 方案 A / 回归，不赌新盘。  
3. **历史案例**（第三方、藏干、关系链、议题污染、closed-menu 超时、辅轨 claim 孪生）维护正负样本；改逻辑先跑回归再 Lab。  
4. **本文随踩坑变厚**：新页专属风险补进对应节；流水账与签字只进活文档。
