# 主辅双提醒 · 独立附加交付规格

> 产品决策 SSOT（2026-10，修订：宏观四段）。实现见 `lib/companion/**`、报告下方 `PojuCompanionFrame`。

## 1. 产品形态

一次购买 = 六页交付报告 + **报告下方同级独立框**（atmos 式 30 金格）+ **服务端权威 30 日滴灌**（可选同步邮箱）。

- **不**并第 7/8 页、**不**塞 P6、**不**每日奇门重铸。
- 日变更底层 = **八字流日**（`buildAtmosEngineSnapshot`）× **封版锁定的 P1 主辅战略**（用户原题锚定）。
- **不**每日轮转 P3 具体 means：报告管执行策略；陪伴不知进度，只给宏观提醒。
- 金格 = **仅网站 UI**；每日邮件 = **当天内容页**（四段 + 依据），不含金格。

## 2. 日稿结构（用户可见）

| 槽 | 职责 |
|----|------|
| `today_is` | 今天是什么 — 今日场域/气口（白话，吃透引擎） |
| `suitable` | 今天适合 — 对本题主辅边界的宜（宏观） |
| `unsuitable` | 今天不宜 — 宜按住的冲动（宏观） |
| `suggestion` | 建议 — 一条总拿捏（态度/时机/边界；可点主线备线，禁具体作业） |
| `evidence` | 依据折层 — `⟦t:⟧` 金字 + 大白话连接（流日根） |

自检：删原题或删 P1 主辅须垮；前四段零裸专名；换日读感应变。

**品牌/合规**：决策陪练口径（不算命、不占卜、不恐吓）。前四段禁气口/吉凶/运势恐吓腔。evidence 用能量白话摘要或合法 `⟦t:slug|白话⟧`；禁引擎字段名、cueCode、英文枚举进标记。

## 3. 铁律口径（已修订 `00-core`）

- 对话主链路仍本机 AES；服务端窄口仅 `CompanionJob`（brief、流日 pack、按日稿、邮箱、发送状态），窗结束硬删。
- 邮箱用于自包含 HTML 交付附件 + 可选每日提醒（非「仅 PDF」）。

## 4. 后台无感日更

用户不打开站也可：cron/队列提早一天生成 D+1 → `delivered` 落库。  
打开/登录后按 Job 渲染：今日高亮、已交付日可点。  
邮箱开关开时：当地 08:00 发**当天内容页**（HTML 附件或等价单页）。

## 5. CompanionJob 字段（概念）

| 字段 | 说明 |
|------|------|
| `id` | job id |
| `session_id` / `profile_id` | 关联 |
| `email` / `timezone` / `mail_opt_in` | 投递 |
| `delivery_day_key` / `ends_day_key` | 窗 |
| `brief` | P1 主辅战略摘录（+ 可选 P3 means 存档，日更不轮转） |
| `liuri_pack` | 30 日 snapshot |
| `days[i]` | 状态 + `CompanionDayCards` v2 |
