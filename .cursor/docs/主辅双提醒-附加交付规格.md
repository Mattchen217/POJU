# 主辅双提醒 · 独立附加交付规格

> 产品决策 SSOT（2026-10）。实现见 `lib/companion/**`、报告下方 `PojuCompanionFrame`。

## 1. 产品形态

一次购买 = 六页交付报告 + **报告下方同级独立框**（atmos 式 30 金格）+ **服务端权威 30 日滴灌**（可选同步邮箱）。

- **不**并第 7/8 页、**不**塞 P6、**不**每日奇门重铸。
- 日变更底层 = **八字流日**（`buildAtmosEngineSnapshot`）× **封版锁定的 P1/P3 主辅手段**。
- 金格 = **仅网站 UI**；每日邮件 = **当天内容页**（主+辅双卡），不含金格。

## 2. 铁律口径（已修订 `00-core`）

- 对话主链路仍本机 AES；服务端窄口仅 `CompanionJob`（brief、流日 pack、按日稿、邮箱、发送状态），窗结束硬删。
- 邮箱用于自包含 HTML 交付附件 + 可选每日提醒（非「仅 PDF」）。

## 3. 后台无感日更

用户不打开站也可：cron/队列提早一天生成 D+1 → `delivered` 落库。  
打开/登录后按 Job 渲染：今日高亮、已交付日可点。  
邮箱开关开时：当地 08:00 发**当天内容页**（HTML 附件或等价单页）。

## 4. CompanionJob 字段（概念）

| 字段 | 说明 |
|------|------|
| `id` | job id |
| `session_id` / `profile_id` | 关联 |
| `email` / `timezone` / `mail_opt_in` | 投递 |
| `delivery_day_key` / `ends_day_key` | 窗 |
| `brief` | 主辅摘录 |
| `liuri_pack` | 30 日 snapshot（或可重算种子） |
| `days[i]` | `pending\|generated\|delivered\|sent\|failed` + cards |

## 5. UI

- 完整报告框下方再开同级框。
- 框内 30 金格 + 右下「每日提醒同步发送到我的邮箱」。
- 点格 → 主/辅双卡 Sheet。

## 6. 不做

每日奇门、Syncro 并进、装进六页 DAG、每天邮件重发整份金格、收件箱正文内跑完整 React SPA。
