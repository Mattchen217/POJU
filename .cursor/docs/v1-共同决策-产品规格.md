# v1 共同决策 · 产品规格（落地）

> 与计划「共同决策落地计划」对齐。最后更新：2026-10-25。

## 口径

- Flex **$19.99 / 1 PASS**：仅个人决策。
- Duo **$59.99/月**：绑定 2 账号，共享 5 PASS；个人扣 1，共同决策扣 2（各记 1）。
- 共同决策 = 现网 **dyad 单人决策 × 2**：共同问题 + 对方授权出生信息；互不可见聊天/报告/提醒/出生原文。

## 表与 API

| 资源 | 路径 |
|------|------|
| Migration | `supabase/migrations/20261025_duo_household_joint.sql` |
| Household | `GET /api/household/me` · `POST /api/household/invite-seat` · `POST /api/household/accept-seat` |
| Joint | `POST /api/joint/create` · `POST /api/joint/accept` · `GET /api/joint/list` · `GET /api/joint/:id` |
| UI | `DuoHouseholdCard`（账户 Profile）· `JointDecisionPanel` · `/account/household/accept` |

## 扣费

- `consume_household_pass` RPC + `consumePassSmart`（pivot 优先家庭池）。
- Joint accept：`joint:{id}:a` / `joint:{id}:b` 双扣，幂等。

## 客户端

- `hydrateJointSessionFromSeed`：本地建 session，`joint_decision=true`，跳过对方盘芯片。
