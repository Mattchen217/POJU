## 0. 问题定义（类别，非追句）

| 类别 ID | 现象 | 根因 | 非根因（禁按此修） |
|---------|------|------|-------------------|
| `p4_positive_ex_copy` | 换人换盘仍出「深呼吸三轮 / 背靠实墙 / 通风开阔 / 温水」同一串 | moat-feed / duty **整句可抄范文** + 白名单被当成必出清单 | 「养生黑名单」删白名单类别；把 MVP/股权塞进 P4 |
| `p4_upstream_homo` | 六维 strategy/means 同义换皮 | assign `claim_seed` / write 批断机制撞车 → 正文论证源同一根 | 只加 fill 去重正则追 Lab 句 |
| `p4_body_judgment_unlink` | 正文像菜单腔，删批断仍成立 | fill 未强制「每维手段须能被本维批断解释」 | 把正文改回批断翻译 |
| `p4_pillar_bleed` | 意象≈仪轨≈降温；两段站位同义 | 菜单候选语义过近；维职责未在派工锁死 | 用闸门强迫命中某正例词 |

**人审合格（三问仍有效，措辞对齐铁律）**

1. 局势：删奇门主客/微剧本锚 → 垮；有谁压谁 + 攻守 + 近窗。  
2. 意象：删用忌锚 → 垮；气场稳压，非性格鸡汤。  
3. 仪轨：手段 ∈ 节奏/场域/身心**类别**，且能被本维批断解释；**不是**合同/话术；**不是**整页同一套范文动作。  
4. 加测：**换盘抽样**——两案 P4 means 不得共用同一串 verbatim 仪轨句。

## 1. 目标架构（修完后长什么样）

```
Fact-pack / 奇门锁盘 / 用忌 / 十神
        │
        ▼
assign：6 条互异结构主张（moat_class + 不同 cite 核）

        │
        ▼

        │
        ▼
正文：可执行暗锦囊（结论）← 批断扎根（论证）
```

**菜单 / duty 只保留**

- 宏观目标（三柱职责、暗锦囊 vs P3）  
- 禁区硬表  
- 类别上限（仪轨 ∈ {节奏差, 空间切断, 体态收势, …}——**类别名，不要范文句**）  
- 本案结构化料：主客、stance、用忌、十神、微剧本敌我时空、派工锁定 path  

**菜单 / duty 必须删掉**

- `means1: …深呼吸三轮…` / `means2: …背靠实墙…` 等整句可抄草稿  
- 「整句抄写下列 means」类指令  
- duty 里把具体茎当成「请输出这些词」的枚举（可改为「类别上限见规格；具体动作由本盘批断长出」）
