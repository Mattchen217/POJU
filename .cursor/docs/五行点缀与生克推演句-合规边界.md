## 调候叙事人工抽查（本波不做自动闸）

完整调候/生克推演句式（含「英文标签+调候比喻」，如 `耗元fire` +「靠近水缓冲」）比单字五行点缀风险更高。自动化拦截留待合规口径升级后再做。

| 项 | 约定 |
|---|---|
| 范围 | 完整调候叙事、完整「X生Y / X克Y」推演、英文元素标签+调候比喻组合 |
| 负责人 | 交付质量负责人（产品侧）在每次**合并前人工通读**勾选（见《交付质量对照清单-合并前人工通读检查单》） |
| 频率 | 每份上线前重生案至少 1 次；另每两周抽 1 份近线报告 |
| 不通过 | 记入 leak→staging 禁词/映射候选；严重则阻断合并，升级合规口径后再自动化 |

抽查时对照本文件「允许/禁止」表；发现「英文标签+调候」实例须单独记一条 staging，不得只因「没有汉字五行」放过。
