## 0. 产品定位与护城河（必须先读）

### 0.0 护城河必须先成立

Eastern OS 的核心 **不是**：

- 让 AI 陪用户聊天；  
- 把出生信息丢进模型后生成一份命理报告。

它的 **价值链** 必须同时成立，缺一环则护城河不成立：

| 环节 | 做什么 | 为何不可缺 |
|------|--------|------------|
| **1. 了解这个人** | 出生信息 → **本地传统命理真算**；**多轮对话** → 现实处境、资源、约束、目标与细节 | 命理提供盘面结构理解；对话补充命理无法提供的现实信息。两者结合才形成多维理解 |
| **2. 分析这个问题** | 传统命理框架与现代心理学、行为科学、决策科学、经济学、概率分析等 **分别用于不同层面** | 不是装饰性贴标签；是分析体系里的真实组成部分 |
| **3. 给出针对这个人的决策方案** | 结合其实际资源、约束、目标与所面临问题，给出具体策略、执行原则、风险边界与验证标准 | 付费买的是方案，不是画像或陪聊 |

**关键锁定**

- **出生信息与命理分析不是营销装饰**，而是分析体系的真实组成部分。  
- **多轮对话不是可有可无**，它负责补齐命理无法提供的现实信息。  
- **两者结合**，才是 Eastern OS 要建立的产品特点。

**双向失守即产品变质**

| 若删除… | 产品退化成… |
|---------|----------------|
| 命理分析，只留现代科学 + AI 对话 | 通用决策/心理咨询工具，失去原设计的重要差异化 |
| 多轮现实对话与现代科学，只留命理 | 传统算命报告，无法实现现代个人决策支持 |
| 针对此人的方案，只剩分析散文 | 内容消费，不是决策交付 |

工程与验收上的护城河尺（与 §3 双轨删段自检一致）：删掉命理依据后关键主张「谁都适用」= 失守；删掉现实对话信息后执行建议仍可套任何人 = 失守；删掉科学依据后只剩术语注水或完全无方法层 = 科学轨失守。

### 0.1 对外中文定位（Canonical 一句）

> **Eastern OS 是一款以现实问题为导向、以个人出生信息经本地传统命理真算后的结构为个性化分析依据、以现代多学科方法为现实分析与推理基础的 AI Agent 决策产品。**

| 短语 | 含义 | 刻意不说成 |
|------|------|------------|
| **以现实问题为导向** | 用户要解决的是职业、关系、人生选择等现实困境 | 不是单纯来拿一份八字解读 |
| **以个人出生信息经本地传统命理真算后的结构为个性化分析依据** | 用户输入的是**出生信息**；产品用本地引擎算出八字等结构，作为个体化分析的**实质性组成部分**（非装饰） | 不是「八字已经过现代科学验证的预测依据」；对外可不堆「八字」一词，对内/依据层仍用真算结构 |
| **以现代多学科方法为现实分析与推理基础** | 心理 / 行为 / 决策 / 经济 / 统计 / 系统思维等，用于现实条件、选项、风险与行动策略 | 不是用科学去「证明」命理 |
| **AI Agent 决策产品** | 多轮对话理解处境 → 组织双框架分析 → 交付个性化方案（+ 可选预生成 30 日锚定） | 不是只会吐静态命理 PDF 的生成器；也不是持续回访教练（见 §1） |

**「出生信息」还是「八字信息」？**

| 表述 | 适用 |
|------|------|
| **出生信息**（推荐对外主句） | 更准确描述用户输入；审核与大众文案更不易被直接打成「算命产品」标签；与「先收集生辰再真算」一致 |
| **八字 / 命理结构**（对内、依据层、护城河验收） | 真算引擎与删锚自检的对象；不可对外改成「出生信息」后就删掉命理承重 |
| **不推荐单独写「以八字信息为依据」作唯一对外句** | 易被读成算命报告；也易让人以为模型直接吃八字文本，而非本地真算 |

两者定位不同，**不必混为一谈**：出生信息 → 真算结构 = 传统框架下的个体化视角；现代多学科 = 现实可行性与方法层。

**对内一句话（工程/提示词）**仍可用：

> 先把现实问题、期望与细节聊透，再以「本地命理真算 + 现代多科学」为双底层推理，最后一次性交付个性化决策方案（及可选预生成 Daily Anchor）。

用户付费买的是 **处理现实决策的方案**，不是命理人格散文，也不是通用心理课。  
产品形态是 **纯一次性交付**（§1），但一次性 **不降低** 对 §0.0 价值链三环的要求。

### 0.2 旧定位 → 新定位（对照）

| 维度 | 旧（命理单锚定） | 新（现实先行 · 双框架） |
|------|------------------|-------------------------|
| **分析起点** | 生辰 / 命盘结构为主入口 | **用户真实困境、期望、约束、细节** 为主入口；无聊透则不进入深交付 |
| **底层框架** | 主要锚定命理批断说话 | **双底层**：本地命理真算 **与** 现代多科学（心理 / 行为 / 决策 / 认知 / 经济等）**同时作为推理与输出的必要条件** |
| **推理方式** | 从盘面推性格与药方，现实信息多为补充 | 在已对齐的现实问题之上，**同时**用命理结构与科学机制推理，再收敛主辅与行动原则 |
| **输出依据** | 折叠依据以命理为主（如单轨 `bazi_basis`） | 挂依据模块必须 **命理依据 + 科学依据** 两段（见 §3） |
| **模型角色** | 「懂命理的分析师」 | 「懂现实决策的咨询系统」——命理是独特视角，科学是方法层，**两者都要，缺一不可** |
| **禁止滑回** | — | 禁止只看命理说话；禁止只用科学空谈、丢掉盘面独有性；禁止未聊透就空口深算 |

### 0.3 端到端产品流程（新）

```text
① 现实对齐（对话门）
   聊透：主问题 · 处境细节 · 阶段性期望 · 资源/约束 ·（必要时）关系中的对方信息
   → 用户确认「理解对了」之前，不进入双框架深推理交付

② 双底层分析与推理
   命理轨：本地引擎真算（八字/岁运等结构数据）→ 结构解释与差异化约束
   科学轨：心理 / 行为 / 决策 / 认知等机制 → 偏差、权衡、执行与验证方法
   现实轨：用户已确认事实与硬约束 → 可执行边界（优先级最高）

③ 收敛与一次性交付
   九模块决策报告（当场交付）
   + 可选：与同一次分析一并预生成的 30 日 Daily Anchor（按日解锁/推送，本质仍是同一次购买的内容分发）
   → 流程结束。无回访收集、无进度看板、无自动改策略。
```

**顺序硬规则**：先现实对齐，再双框架推理，最后一次性交付。  
不是「先出命理结论，再找现实凑合」；也不是「先出科学建议，再贴八字注脚」。

**商业硬规则**：一次 PASS = 一次问题的完整交付。用户问题有进展或出现变数 → **新 PASS、新对话、新报告**（新问题），不在旧交付上打补丁。

### 0.4 双底层框架各自做什么

| 底层 | 必要条件含义 | 不做什么 |
|------|--------------|----------|
| **本地命理真算** | 推理与关键主张须能挂上盘面结构；删掉命理依据后「谁都适用」= 失守 | 不预测具体事件；不恐吓；不把传统解释冒充科学事实 |
| **现代多科学** | 推理与行动/验证设计须能挂上本案相关机制；科学依据不得注水术语 | 不宣称临床诊断；不宣称「科学验证了八字」 |
| **现实信息** | 方案可执行性以用户陈述与硬约束为准；与假设冲突时允许纠正 | 不在信息缺口上假装已可执行 |

### 0.5 交付物一句话

> **不是关于你是谁的报告，而是关于你正在面对什么、有哪些选择、如何走出下一步的个人决策方案**  
> ——外加围绕同一决策主题的 **每日决策锚定**（非任务催办）。

用户读完报告，至少应能回答：

1. 我现在真正的问题是什么？  
2. 为什么我会卡在这里？  
3. 结合我的情况，有哪些值得考虑的选择？  
4. 从现在起我应依据什么原则行动，以及怎样判断该推进 / 调整 / 停止？

**推理与输出硬规则（摘要）**：生成各模块前，必须以 **聊透后的现实信息 + 本地命理真算 + 现代科学方法** 为必要条件；折叠依据默认 **命理 + 科学** 两段（§3）。正文围绕同一现实决策，禁止半页八字散文 + 半页心理学散文的拼接。

## 1. 纯一次性交付：两件套与禁区

### 1.0 商业与产品总原则（锁定）

> **Eastern OS v1 = 一次性咨询交付产品，不是订阅式教练 / 不是持续顾问。**

| 原则 | 含义 |
|------|------|
| **一次 PASS · 一次问题 · 一次交付** | 聊透 → 双框架分析 → 报告（+ 可选预生成 30 日锚定）→ **结束** |
| **30 日提醒仍是一次性** | 与同一次分析**预生成**好约 30 条内容，按日解锁/推送；**不是**每天按用户新状态再推理，**不是**回访机制 |
| **无回访闭环** | 不做进度收集、不做策略改版、不做「回来告诉我结果再优化」 |
| **变了就重买** | 问题有进展、出现变数、或想问新题 → **重新购买 PASS，作为新问题再走全流程** |

这与「报告里不写死 30 天任务表」一致：既不跟踪执行，也不在旧单上打补丁。

### 1.1 两件套

| 产品模块 | v1 | 职责 | 明确不做 |
|----------|-----|------|----------|
| **Personalized Decision Report** | **必做** | 当场交付完整九模块决策方案 | 固定 30 天任务表；假装管用户日程；替代法律/医疗/投资意见；回访改稿 |
| **30-Day Daily Anchor** | **可含在同一次 PASS** | 预生成、按日分发的决策锚定（策略一致、角度轮换） | 按用户当日实况重算；催办任务；收集反馈改策略；独立于报告的第二套判断 |

**已移出 v1 范围**：Decision Record / 任何「主动反馈 → 重评旧报告」形态。情况变了 = **新 PASS**，不是旧单续写。

### 1.2 两件套关系

```text
同一次 PASS / 同一次分析
├── 报告（即时全文）     → 方案、原则、调频、风险边界
└── 30 日锚定（预生成） → 按日释放已写好的锚点；写完即冻结，不再根据回访改写
```

用户可关闭推送（退订通知）——这是通知偏好，**不是**「回来更新案情」入口。

## 2. 报告标准架构：9 个内容模块（不锁页数）

**章节数 ≠ 页数。** 一章可以是 1 屏，也可以是多屏。简单题可合并显示，但 **分析链路不得缩短**；复杂题（职业转型 / 创业 / 关系等）应写满各模块深度。

专业性来自：**分析深度、建议可执行性、双轨依据透明度**——不是页码，也不是注水重复。

**依据总规则见 §3；每模块 A/B 写什么见 §4。** 现网「只有 `bazi_basis`」的提示词与闸门 **不能直接沿用**，必须按双轨重写。

### 模块总表

| # | 模块 ID | 名称 | 挂双轨依据 | 科学轨优先学科（示意） |
|---|---------|------|------------|------------------------|
| 01 | `decision_brief` | Decision Brief — 决策简报 | **不挂**（transition；结论来自后续承重模块） | — |
| 02 | `situation_analysis` | Situation Analysis — 处境与问题诊断 | **挂**（科学轨偏重事实分层；命理轨点到与本题相关的结构张力即可） | 决策科学、系统思维 |
| 03 | `personal_decision_patterns` | Personal Decision Patterns — 个人决策模式 | **挂**（双轨对等；本模块是双轨结合的示范页） | 心理学、行为科学、认知科学 |
| 04 | `bottleneck_analysis` | Bottleneck Analysis — 核心障碍分析 | **挂** | 行为科学、认知科学、系统思维 |
| 05 | `strategic_options` | Strategic Options — 战略选项比较 | **挂** | 决策科学、经济学、统计学/概率 |
| 06 | `recommended_strategy` | Recommended Strategy — 主策略与备选 | **挂**（护城河核心页） | 决策科学、经济学、社会学（关系/环境题） |
| 07 | `execution_guidance` | Execution Guidance — 行动策略与执行原则 | **挂** | 行为科学、决策科学、认知科学 |
| 08 | `self_regulation` | Self-Regulation — 自我调频 | **挂** | 心理学、行为科学、认知科学 |
| 09 | `validation_review` | Validation & Review — 风险、验证与复盘 | **挂** | 统计学/概率、决策科学、认知科学 |

可选 **附录**：命盘摘要、术语、计算细节——主报告不堆干支百科；附录**不要求**双轨科学依据。

> 学科列是 **提示词选科与闸门提示**，不是正文堆砌术语清单。每模块只用 1–3 个真正相关的机制，禁止八科全开。

## 3. 双轨依据（全报告硬规则）

### 3.1 产品原则

接入现代科学后，命理不再是唯一承重依据。对**每一个挂依据的模块**，用户打开「依据」时默认看到 **两段独立内容**：

| 段 | 字段建议（工程） | 职责 | 删段自检 |
|----|------------------|------|----------|
| **A. 命理依据** | `metaphysics_evidence`（可含 `chart_anchors` / `bazi_basis`） | 用本地真算结构解释「为何是此人 / 此局」 | 删掉 A 后，主结论若变成「谁都适用」→ **命理轨失守 → 废稿** |
| **B. 科学依据** | `science_evidence` | 用现代学科机制解释「为何这样判断 / 这样安排更可能做成」 | 删掉 B 后，主路径仍可由 A + 现实事实支撑；但若 B 只是空术语或与本案无关 → **科学轨失守 → 废稿** |

另有贯穿标签（可嵌在 A/B 句内或旁注）：

| 类型 | 含义 |
|------|------|
| 用户明确陈述的事实 | 对话 / 收集中已确认 |
| 根据事实的推导 | 推理须可跟随 |
| 尚待验证的假设 | 不得写成定论 |
| 传统命理体系内解释 | 属 A 轨 |
| 现代方法建议 | 属 B 轨；不冒充临床诊断或已验证的八字科学 |

**正文 vs 依据**

- **正文**：统一叙事，围绕现实决策；**不要**左右分栏写成两份报告拼接。  
- **依据层（折叠）**：**必须**分 A/B 两段。  
- **推理过程（提示词）**：生成前必须同时完成「命理结构推理」与「科学机制推理」，再写正文；禁止先写通用建议再事后贴双轨注脚。

### 3.2 证据优先级（冲突时）

1. **现实事实与安全边界**（法律、健康、已确认截止日期、资金硬约束）— 最高  
2. **用户可纠正的陈述** — 命理/科学假设与用户纠正冲突时，以纠正后的现实为准做执行层  
3. **命理轨 A** — 主路径差异化、结构归因、东方处局/调候的不可替理由  
4. **科学轨 B** — 偏差识别、选项权衡、行动设计、验证指标的方法支撑  

允许 A 与 B **结论不完全一致**并分别展示；**禁止**为「看起来融合」编造虚假一致性，禁止「科学验证了八字 / 八字证明了某心理理论」。

### 3.3 现代学科闭集（v1 可引用）

| 学科 | 在报告中的合法用途 |
|------|-------------------|
| 心理学 | 目标、动机、价值观、情绪与内在冲突（非临床诊断） |
| 行为科学 | 拖延、习惯、损失厌恶、现状偏好等机制 → 执行与调频 |
| 决策科学 | 选项比较、权衡、决策树思维、行动策略结构 |
| 认知科学 | 认知偏差、信息处理限制、判断误差 |
| 经济学 | 机会成本、资源配置、激励、风险收益 |
| 统计学与概率论 | 区分事实 / 假设 / 不确定性；验证信号的可观察性 |
| 社会学 | 家庭、组织、关系与环境对选择的影响 |
| 系统思维 | 因果链、反馈循环、长期影响 |

**提示词要求**：点名机制时须落到**本案**（用户事实或已锁策略），禁止只抛学科名词。

### 3.4 Schema / UI / 提示词影响（实现必读）

相对「仅命理 `bazi_basis`」的现网，v1 至少变更：

1. **Schema**：挂依据模块增加 `metaphysics_evidence` + `science_evidence`（或等价双段）；`science_evidence` 建议含 `mechanisms[]`（机制短名）+ `tied_to_case`（对应本案哪条事实/行动）。  
2. **UI**：依据折叠面板固定两小节标题（如「命理依据」「科学依据」）；正文区不强制双栏。  
3. **提示词**：每模块独立 duty——先产出双轨依据草稿/锚，再写正文；科学轨按本模块「优先学科」选科，禁止全科堆砌。  
4. **闸门**：  
   - 缺 A 或缺 B（除 01 不挂依据）→ fail  
   - A 删后谁都适用 → fail（命理承重）  
   - B 无本案绑定 / 纯术语 → fail  
   - A↔B 互相冒充（科学口吻写命理定论，或命理口吻宣称科学证明）→ fail  
5. **喂料**：命理侧继续本地真算 fact-pack；科学侧不需假「测评引擎」，但需 **机制闭集 + 本案现实字段** 作为选科输入。

### 3.5 双轨删段自检（人审 / 机闸共用）

```text
对每一条关键主张（策略、障碍、调频建议、风险熔断等）：
1) 去掉 metaphysics_evidence → 若主张变成「谁都适用」= 命理未承重 → 重写
2) 去掉 science_evidence → 主路径仍应站得住，但「为何这样安排执行/验证」应变薄；
   若去掉 B 后主张完全不变且 B 原文无本案机制 = 科学轨注水 → 重写 B
3) 去掉用户现实事实 → 若执行建议仍可照抄给任何人 = 未扎现实 → 重写
```

## 4. 分模块规格（必写 / 禁写 / 双轨依据）

以下每一模块的提示词必须单独实现：**选科闭集 → 双轨依据 → 正文**（01 跳过依据层）。不得复用「只写 bazi_basis」的旧单轨 prompt。

### 01 · Decision Brief

**必写**

- 当前真正要决定的问题（一句）  
- 最关键矛盾与约束  
- 推荐方向及其成立条件  
- 接下来最值得采取的一步  

**禁写**

- 用简报替代后续完整分析  
- 命运定论、具体事件预测  

**依据**：本模块为 **transition**，**不挂**折叠双轨依据（对齐现网 P1「先给结论头」）。推理仍须吃满盘与现实；依据承重放在 02–09。

**交付结果**：一句话问题 + 一项核心判断 + 一个建议方向 + 一个近期行动方向。

---

### 02 · Situation Analysis

**必写**

- 现状与期望的差距  
- 资源、责任、时间、资金、外部限制  
- 已确认事实 / 待验证假设 / 信息缺口  
- 表面问题与可能深层问题的关系  

**禁写**

- 仅复述用户原话而无结构重组  
- 把猜测写成已确认事实  

**依据 · A 命理**：与本题相关的结构张力/阶段约束（点到为止，不做全盘批命）。  
**依据 · B 科学**：如何区分事实与假设、可控与不可控（决策科学 / 系统思维）；点明信息缺口为何影响选项质量。

**交付结果**：现实问题地图（症状、原因、约束、待验证假设）。

---

### 03 · Personal Decision Patterns

**必写**

- 本题相关的价值排序、风险承受、冲突应对倾向  
- 压力下可能出现的偏差或反复模式（需有用户陈述或行为线索支撑处写清）  
- 与本题相关的传统命理解释，并**标明**为传统体系内解读  
- 区分：用户陈述事实 / 行为证据 / 待验证假设 / 命理解释  

**禁写**

- 泛泛全盘性格报告、与本题无关的十神罗列  
- 将命理推断包装成已证实的心理测量或科学结论  

**依据 · A 命理**：本题相关的命理结构解释（传统体系内）。  
**依据 · B 科学**：动机、风险态度、冲突模式等机制；明确哪些是待验证心理假设。  
**本模块是双轨结合示范页**：A/B 必须都写满且互不冒充。

**交付结果**：与当前决策相关的个人模式短析，不是人格说明书。

---

### 04 · Bottleneck Analysis

**必写**

- 最关键的 1–3 个障碍  
- 成因、维持机制、彼此影响  
- 可控 / 可影响 / 暂不可控  
- 解除哪一个最可能改局面  

**禁写**

- 仅换措辞重复第 02 章  
- 无依据地堆砌障碍数量  

**依据 · A 命理**：结构阻力如何对应这些障碍（删 A 后障碍排序应垮或泛化）。  
**依据 · B 科学**：拖延、损失厌恶、沉没成本、反馈循环等**本案绑定**机制。

**交付结果**：优先障碍清单 + 双轨依据。

---

### 05 · Strategic Options

**必写**

- 2–4 个现实可行选项（可含维持现状、小规模试验、暂缓）  
- 各路径：收益、成本、风险、时间、可逆性  
- 成立前提与失效条件  
- 仍缺哪些信息、可用什么小行动验证  

**禁写**

- 为凑数编造不现实选项  
- 四条路径同等推销、无比较维度  

**依据 · A 命理**：各选项与命盘结构的契合/张力（比较用，不作吉凶恐吓）。  
**依据 · B 科学**：权衡维度、机会成本、可逆性、不确定性（决策科学 / 经济学 / 概率语言）。

**交付结果**：可比较的选项表（或等价结构）+ 双轨依据。

---

### 06 · Recommended Strategy

**必写**

- 推荐主路径 + 选择理由（须能回答「为何是你 / 为何是现在」）  
- 备选路径 + **何时切换**  
- 关键前提、依赖、资源要求  
- 应主动放弃或暂缓什么  
- 停止 / 退出 / 重新决策的触发条件  

**禁写**

- 仅用几句口号概括「核心章节」  
- 无边界的励志结论  

**依据 · A 命理**：**主路径承重轨**——删 A 后推荐理由必须垮。  
**依据 · B 科学**：在现实约束下为何此排序更合理（权衡、风险收益、关系/环境因素）。  

**护城河自检**

- 删 A → 主路径理由谁都适用 = 废稿。  
- 删 B → 仍知「推荐哪条」，但缺方法层说服力；B 不得注水。  
- 禁止伪融合措辞。

**交付结果**：主 + 辅 + 前提 + 退出 + 双轨依据。本模块与 07 同属付费核心，应写厚。

---

### 07 · Execution Guidance（原「行动计划」正式更名）

**必写**

- 当前阶段优先推进 / 验证什么  
- 可立即采取的具体行动建议及理由（示例级，非日历）  
- 行动顺序原则：先验证什么、暂缓什么  
- 推进 / 调整 / 停止的判断条件  
- 降低风险、避免常见决策偏差的执行原则  

**禁写（硬）**

- **固定的按日或按周任务表作为标准交付**（含「第 N 天必须完成 X」类 30 天甘特）  
- 「增强行动力」「抓住机会」等无对象、无标准的空建议  
- 合同全文、完整话术剧本、专业代做  

**依据 · A 命理**：行动原则如何从结构/节奏约束长出（删 A 后手段若完全通用 = 废稿）。  
**依据 · B 科学**：**本模块科学轨最重**——行为设计、验证实验、偏差防范如何支撑这些执行原则。

**交付结果**：行动策略与执行原则 + 双轨依据。

---

### 08 · Self-Regulation

**定位**：解决 **如何以可持续状态执行策略**，不是再列一遍外部任务。

**必写**

- 本题下值得关注的压力反应与行为风险  
- 如何识别冲动、拖延、反复犹豫、过度投入  
- 适合该用户的反思、休息、信息限制、重大决定前暂停机制  
- 可重复使用的调节方法；若用东方框架（意象 / 节奏 / 轻仪轨等），须个性化且标明传统属性  
- 何种状态下宜继续推进，何种状态下应先暂停重大决定  

**禁写**

- 复读第 07 章任务清单  
- 声称某五行 / 气场调整能确定改变现实结果  
- 把气场、运势等不可验证解释包装成科学结论  
- 通用鸡汤冥想页（与本题、与此人无关）  

**依据 · A 命理**：调候 / 节奏 / 仪轨类建议的结构来源（传统视角，标明属性）。  
**依据 · B 科学**：情绪与认知调节、习惯与环境设计等机制；**不得**把 A 改写成「科学证明」。

**对照例（离职创业）**

- 策略：先验证客户需求，再决定是否离职。  
- 执行原则：两周内用低成本方式拿到真实反馈的判断标准。  
- 调频：每周固定复盘；焦虑改计划时先分「新证据 vs 情绪」；重大决定前走约定暂停流程。  

**验收**：整章挪进「执行原则」应违和（对己 ≠ 对事）。

---

### 09 · Validation & Review

**必写**

- 方案可能奏效的可观察信号  
- 原判断可能错误的信号  
- 关键风险、预警、退出条件  
- 复盘时应回答的问题（时间点可为建议，非强制日程）  
- 重大变化时哪些模块需重评  

**禁写**

- 把推荐方案写成不可质疑的结论  
- 无可观察标准的「你会感觉好转」  

**依据 · A 命理**：结构特有坑 / 熔断与本题盘面的对应（删 A 后熔断若通用 = 弱）。  
**依据 · B 科学**：信号如何可观察、如何区分噪声与有效反馈（概率 / 决策 / 认知偏差）。

**交付结果**：验证与退出仪表盘 + 双轨依据。供用户**自行**对照现实；若前提大变，产品口径是 **新购 PASS 重问**，不是系统回访改旧报告。预生成 Daily Anchor 只复用本模块写死的主题/边界话术闭集，不另开实时接口。

## 5. 30 天提醒：Daily Decision Anchor（预生成分发）

### 5.0 与「一次性」的关系（先读）

30 日锚定 **不是** 持续服务，而是：

> **同一次分析结束时，一次性预生成最多约 30 条锚点内容 → 按日历日解锁/推送。**

- 生成时刻：与报告同一分析批次（或紧随其后的批处理），之后 **内容冻结**。  
- 「每日独立」指：30 条彼此角度不同，不是同一句复读——**不是**每天凌晨根据用户新反馈再跑模型。  
- 流日/传统时间框架若使用：在预生成时按「交付日起第 n 日」的历法窗口算入各条，而不是上线后再实时改写策略。  
- 用户中途情况变了：产品 **不** 提供改锚点/改报告；引导 **新 PASS 新问题**（可提示关掉旧推送以免骚扰）。

### 5.1 核心规则（v1）

> **策略一致、预生成多视角锚点、按日分发。**

- **策略一致**：不偏离报告的决策主题、主辅路径与风险边界。  
- **视角轮换**：不是报告摘要复读，也不是第 N 天任务；各日可换**决策视角**锚定同一策略。  
- **禁止**：为凑 30 天新鲜感而虚构吉凶、重复空话、强行制造无依据差异；禁止做成回访式对话。

### 5.2 视角示例（非日程）

若主策略是「先验证市场需求，再决定是否扩大投入」，提醒可轮换例如：

| 视角 | 当日锚定重点 |
|------|----------------|
| 验证导向 | 优先获取真实证据，而非完善未验证设想 |
| 风险导向 | 检查新增投入是否依赖未证实假设 |
| 行动导向 | 若有低成本验证机会，优先能产生真实反馈的行动类型 |
| 节奏导向 | 短期反馈不佳时，先判断反馈是否有代表性，再决定是否推翻策略 |
| 边界导向 | 关键前提变化时重评方案，而非机械坚持原方向 |

### 5.3 生成依据三层（优先级从上到下约束）

1. **决策主线**：报告中的决策主题、主辅策略、风险与退出边界。  
2. **当日视角**：提醒所用时间框架 +（可选）传统命理/流日规则所选关注角度；使用时须标明传统文化属性，**不得**声称科学预测当日结果。  
3. **现实约束**：用户已明确的截止日期、紧急事项、已知条件；**优先于**一般择时参考。

无实时状态时：只能给基于**已有信息**的当日参考；禁止假装掌握当天遭遇、情绪或「今日必成」。

### 5.4 建议结构（单条提醒）

每条宜包含（文案可本地化，字段可工程化）：

1. **今日主题句**（贴合策略视角，非空口号）  
2. **适合关注** — 行动/信息类型  
3. **今天可以做** — 类型化建议（非强制任务勾选）  
4. **今天需要避免** — 与本题风险边界相关  
5. **今日锚点** — 一条可记住的决策原则  

每条应能回溯到：`决策主题 + 至少一条报告策略/边界原则 +（可选）一条调频原则 +（可选）传统视角标注`。

### 5.5 运行前提（一次性产品）

- 不以「用户是否完成任务」为前提；无完成率、无催办。  
- **不**要求、**不**提供每日汇报或案情更新入口。  
- 内容预生成后冻结；不因用户未读/未执行而改写后续日。  
- 用户可 **关闭推送**（通知偏好）。若自行感到主题已变：关掉旧推送 + **新购 PASS**，系统不提供「更新旧案」流。  
- **禁止**把推送做成「今天过得怎么样？回复我以便调整」类回访。

### 5.6 与报告的数据关系

| 报告侧 | Companion 使用方式 |
|--------|-------------------|
| 决策主题 | 提醒始终围绕的主题 |
| 主辅策略与风险边界 | 闭集约束；提醒不得否定主策略（除非走到「边界导向」且有依据） |
| 执行原则 | 提供「行动类型」词汇，非任务 ID |
| 自我调频方法 | 可引用稳定原则，不诊断当日心理 |
| 验证与退出 | 条件类提醒的话术来源 |

**禁止**：报告建议做 A、提醒却推动无关的 B；或提醒每日复读同一句策略摘要。

## 6. 验收标准（报告）

开发与人审可用下列清单（打勾证明符合设计，**不**证明命理科学有效性，**不**代替真实用户测试）：

- [ ] **护城河三环齐全**：了解此人（命理真算 + 多轮现实对话）→ 双框架分析本题 → 针对此人的决策方案；缺一环不合格  
- [ ] **定位未滑回**：不是「只看命理说话」；也不是「丢掉命理的通用咨询」；不是纯陪聊  
- [ ] **现实先行**：交付前已对齐主问题 / 期望 / 关键细节；无对齐则不得深交付  
- [ ] **命理非装饰**：出生信息与命理分析实际进入推理与依据，而非营销标签  
- [ ] **对话非摆设**：多轮对话补齐的现实信息实际约束了方案可执行性  
- [ ] **问题准确**：抓住真问题，而非只复述用户描述  
- [ ] **个性化真实**：结合实际经历、资源、约束  
- [ ] **依据透明**：区分事实 / 推断 / 假设 / 命理解读 / 方法建议  
- [ ] **双轨齐全**：02–09 每一模块折叠依据均有命理段 A + 科学段 B；01 明确不挂  
- [ ] **双轨不冒充**：A 不写成科学证明；B 不写成命理定论；无「科学验证八字」  
- [ ] **删 A 自检**：关键主张去掉命理依据后不能谁都适用  
- [ ] **删 B 自检**：科学段绑定本案机制，非术语注水  
- [ ] **方案有差异**：适合此人的路径，非万能建议  
- [ ] **行动可执行**：有对象、原则、条件与停止规则（无假日历亦算可执行）  
- [ ] **风险充分**：前提、失败信号、替代路径、退出条件  
- [ ] **结果可自检**：用户能用报告内信号自行判断；大变则知应 **新购 PASS**，而非期待系统回访  
- [ ] **一次性边界清晰**：无回访收集、无进度闭环；30 日锚定为预生成分发  

另增 Companion 样例验收：

- [ ] 连续多条提醒策略一致且视角有变化  
- [ ] 抹掉表面策略套话后，仍能看出同属一个决策（非万能鸡汤）
