> **地位**：落地计划 Wave 5 操作清单。对照 [`v1-决策交付-产品边界.md`](./v1-决策交付-产品边界.md) §3.5 / §6。

> 最后更新：2026-10-26

## 0. 样例选题

建议用 **离职创业**（或同等复杂度：职业转型 / 关系重大取舍）跑通一次完整 PASS：

1. 现实对齐（议程 5–6 问，答案须有可绑定散文）  
2. 十段出稿（九模块）  
3. 预生成 3–5 条 Daily Anchor 样例  

## 1. 护城河与定位（§6）

- [ ] 护城河三环齐全：真算 + 多轮现实 + 针对此人的方案  
- [ ] 未滑回「只看命理」或「丢掉命理的通用咨询」  
- [ ] 交付前已确认理解；硬推未在低覆盖下绕过（PUSH≥85% 且有散文）  

## 2. 九模块形状

- [ ] 01 `decision_brief` 有结论头；**不挂**折叠双轨依据  
- [ ] 02 含处境卡 + 事实/假设/缺口分层  
- [ ] 03–04 独立模式/障碍页（非旧 foundation 复读）  
- [ ] 05 2–4 选项可比较  
- [ ] 06 主辅 + **exit 必填**；删 A 后推荐理由垮  
- [ ] 07 对事执行；08 对己调频；挪章应违和  
- [ ] 09 risk + close；risk 条依据走双轨折叠  

## 3. 双轨删段三问（§3.5 · 每条关键主张）

对 02–09 各抽至少一条关键主张：

1. [ ] 去掉 `metaphysics_evidence` → 若谁都适用 = 命理未承重 → 废稿  
2. [ ] 去掉 `science_evidence` → 执行/验证方法应变薄；若 B 无本案机制 = 注水 → 废稿  
3. [ ] 去掉用户现实事实 → 若执行建议仍可照抄给任何人 = 未扎现实 → 废稿  

另：

- [ ] 无「科学验证八字」等伪融合  
- [ ] UI 折叠两小节标题正确；缺 B 不得伪装已双轨  

## 4. Daily Anchor

- [ ] 预生成、策略一致、视角有变化  
- [ ] 五槽语义：主题 / 适合关注 / 可以做 / 需要避免 / 今日锚点  
- [ ] 闭集 hints 来自封印 06–09，非仅 brief 切片  
- [ ] 无回访改旧报告口吻
