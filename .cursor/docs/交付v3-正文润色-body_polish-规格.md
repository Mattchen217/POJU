> **定调**：上游做准 / 做真 / 做值钱；本步只做「给人读」。**不是**纠错器，不替代 duty/喂料/闸门。

## 1. 落位

```
judgment → body → gate（机闸+人审）→ body_polish → evidence_soft
```

- **先试点**：仅 `science_action`（P3）Lab 步进。
- 生产 DAG 默认**未接**；Lab 测稳后再决定是否入 Wave。
- `evidence_soft` 仍只动依据折层；润色**不改正文以外的批断**。

## 2. 任务合同（极窄）

| 做 | 不做 |
|----|------|
| 可见字段读感：完整句、语气、locale（含 zh→zh） | 改事实、数字、门槛结论、页角色 |
| 去掉可见层残留电报体 / 刺耳半文言 | 增删 means 条数或改动作指向 |
| 按用户 locale 输出可读正文 | 把 `chart_anchors` 真词写进可见层 |
| 同 JSON 形状回写 | 发明 X%/未收集时长；把已拒路径翻成主推 |

**输入**：闸门通过后的 `page_schema`（首次润色前冻结为 `page_schema_pre_polish`）。  
**输出**：同页 schema；`chart_anchors` **代码侧按 path 盖回草稿**（模型改了也不算）。  
**验收**：润色后再跑 `gateBodyCategoryB`；不过 → **不覆盖**已过闸正文，本步 fail，回改润色提示或上游正文——禁止润色空转重试链。

## 3. 与铁律对齐

- **一次到位**：准/真仍靠 body 枪；润色失败不证明「再翻一次就能修好主张」。
- **闸门不改稿**：润色是独立生成步；闸仍只验。
- **禁案例补丁**：润色禁区写类别（专名族/引号台词/比例占位），不写本案二字。
