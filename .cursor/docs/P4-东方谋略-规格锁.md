## 1. 一句话定位

**P4 = 东方谋略页（暗锦囊）**：基于 **八字（知己）+ 奇门遁甲（知局）** 双核本地真算，通过 **局势交锋 · 意象调频 · 行为仪轨** 三柱，帮助用户在执行 P1/P3 时拿住高维破局暗号。

| 对照 | P3 科学行动（明战术） | P4 东方谋略（暗锦囊） |
|------|----------------------|----------------------|
| 解决 | 硬商务 / 理性工具 | 气场博弈 / 局势演断 / 身心结界 |
| 抓手 | 合同、数字、里程碑、清单 | 攻守隐退、五行意象、仪轨锚点 |
| 主语 | 对方 / 协议 / 交付物 | 局 / 气 / 我的身心与场域 |

内部 key 仍为 `metaphysics_action`；UI 固定标签 = **东方谋略**（见 `DELIVERY_PAGE_TAGS` / `report-blueprint`）。

---

## 2. 算法底层（双核 · 缺一不可）

1. **八字**：日元强弱、喜用忌、大运流年、十神角色等——支撑「意象调频」与部分局势判断。  
2. **奇门**：复用 `lib/qimen`（与 Syncro 同源引擎）——支撑「局势交锋」与「时/方仪轨」真锚。

**失败策略（硬）**：奇门算盘或接线失败 → **重试**；多次仍失败 → **本页显式 fail / 报错**。  
**禁止**：降级为「仅八字」半套交付、禁止用户面「奇门不可用」后仍标 ready、禁止静默用空盘编宫门。

---

## 3. 锁盘幂等（定盘 SSOT）

| 规则 | 说明 |
|------|------|
| 锁盘键 | 本交付 **首次成功算出奇门盘** 的时刻写入 Fact-pack：`qimen_cast_at` |
| 幂等 | Fact-pack 已有奇门字段 → **只读，永不重算**（重跑 fill / 刷新 UI / 多次生成同盘） |
| 新建 | 仅当 Fact-pack 无奇门块且允许新建时算一次并落盘 |
| Lab | 「准备重跑」若要新盘：须 **显式清空** Fact-pack 奇门块；禁止静默换时辰 |
| 非锁点 | **不要**用 Session 开聊 `created_at` 起盘（可能早于交付很久） |

八字喜用与奇门摘要（值符、值使门、用神宫、主客生克等可摘录字段）一并进当前交付 Fact-pack。

## 4. 正文三柱（用户感知）

正文零裸专名（无食神/比肩/丙火/奇门遁甲等报幕）；机制在折叠依据 / 软译。

| 柱 | 主真算源 | 产品问题 | means 形态 |
|----|----------|----------|------------|
| **奇门谋略·局势交锋** | 奇门盘 | 此局宜攻/守/隐/退？ | 战术取向（有门神 cite） |
| **意象调频·五行气场** | 八字用忌旺衰 | 我怎么稳住气、不入对方场？ | 意象稳压（有用忌 cite） |
| **行为仪轨·身心结界** | 奇门时方 + 八字意象可执行锚 | 我此刻做哪几个低门槛动作？ | 白名单仪轨（有 cite） |

旧称「自我调频」降为意象柱的子能力，**不再**作整页主定位。  
旧护城河维名 `timing` / `polarity` / `archetype` 在实现过渡期可映射到三柱（时机≈局势窗、极性≈意象、角色≈局势站位）；新菜单/duty 以三柱叙事为准（Step2）。

### 4.1 行为仪轨白名单（防神棍）

**允许（身心–环境心理学）**

- 时间/节奏：拉开缓冲冷静期、静座片刻再回复  
- 生理/感知：温凉饮、深呼吸、简单体态切换  
- 空间/场域：换通风开阔处、背靠实墙、避开局促逼仄场  

**严禁**：玄学道具买卖、吉祥物/水晶佩戴、符咒仪式、宗教色彩方位摆设；**禁**五行物化（缺水=绿植、缺火=晒太阳）；**禁**把 P3 商务工具写成仪轨。

### 4.2 软译

奇门/八字底层词 → 东方谋略白话，走 **既有软译 SSOT**（含 Syncro `qm_*` / vernacular）扩展，**禁止**只在 moat-feed 另起第二套真理表。正文泄漏裸词按合规审计处理。

## 5. 与 P3 硬隔离

P4 **不得**以以下为 means 主体（出现即废码类别）：  
合同、条款、股权、法律/律师、交接文档、邮件模板、Excel、OKR、补充协议、完整谈判话术剧本、里程碑锁权益等。

闸门：**禁 P3 工具词族**；**不**要求正文必现「涵水/伏火」等口号词（语感靠菜单生长，禁追句）。

自检：

1. 删掉八字+奇门真算锚 → 论述垮。  
2. 手段主语是「局/气/仪」而非「对方协议/交付物」。  
3. 读感是东方谋略锦囊，不是 OKR/CBT 周报，也不是第二份 P3。

---

## 6. 三段管线（不变骨架 · 换料）

1. **assign**：结构主张 + Fact-pack 摘录（八字 **和/或** 奇门结构句）；禁手段白话进 `unit_claim`。  
2. **write**：纯批断展开（可含奇门局势链）；无用户处方。缺出处 → **先扩 Fact-pack**，禁现编。  
3. **fill**：批断 + **P4 东方谋略候选菜单** → strategy/means（三柱）。

质量：**菜单生长优先**；纠错 1+1 封顶；仍不过 → 显式 fail。
