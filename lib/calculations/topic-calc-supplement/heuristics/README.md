# TopicCalcSupplement · 启发式评审机制（轻量）

> 经验边界类字段必须可追溯。本目录是**评审记录落点**，不是口号。

## 规则

1. 每个经验边界启发式 = 一个 `heuristic_id` + 递增 `heuristic_version`（如 `v1`）。  
2. 同输入必须同输出；改行为必须升版本，并新建/更新本目录下对应评审页。  
3. **禁止**在启发式里输出 `push` / `hold` / `retreat` / 「宜冲」「宜守」作为最终裁决——节奏裁决只属于总纲 `cycle_rhythm`（方案 B）。  
4. 元素扶抑表（support/drain/control）算**规则表**，不是经验边界；不必走本评审，但仍需单测。

## 评审页模板

复制 `HEURISTIC_REVIEW_TEMPLATE.md` → `reviews/<heuristic_id>-<version>.md`，填全后再合入代码。

必填：

| 项 | 说明 |
|----|------|
| heuristic_id / version | 与代码常量一致 |
| 作者 / 评审人 / 日期 | 谁写、谁过、何时定版 |
| 对照黄金样例 | 至少 3 个（盘指纹或四柱 + as_of + 期望输出） |
| 通过标准 | 样例全绿；与总纲职责无重叠（无冲守裁决） |
| 已知局限 | 流派分歧处写清「为何选这一派」 |
